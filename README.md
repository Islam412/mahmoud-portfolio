This project includes a clean UI, modern styling (Tailwind CSS), and a fast development setup using Vite.

## Getting Started

### 1) Clone the repo
```bash
git clone https://github.com/Islam412/mahmoud-portfolio.git

2) Install dependencies
bash

npm install

3) Run locally
bash

npm run dev

4) Build for production
bash

npm run build

Project Structure (typical)

    src/ — React source code
    index.html — Vite entry HTML
    tailwind.config.js — Tailwind configuration
    vite.config.js — Vite configuration
